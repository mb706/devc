devc does not ship this file as is. internal/toolbox derives the box profile from it in code
(no user namespaces, no AF_ALG sockets) and writes the result to <toolbox>/seccomp.json.
To update: replace default.json with the file from a newer release, update this note, and run
the toolbox unit tests; they check that the derivation still applies and changes nothing else.
