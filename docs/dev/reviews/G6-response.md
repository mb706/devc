**G6-01 (the boundary tour is not complete) — fixed.** `cli.newEditorCmd` starts VS Code or Cursor attached to a box and warns that its server can act on the host. Compared with the 32 boundary channels of `system.toml`, the tour also lacked the box's own network at level internet, the editor, the desktop sidecar, the dial process, box text to the phone through ntfy, GitHub's API answers to `devc pr`, the login container's output and vendor installers. `flows/trust-boundaries.toml` gained a stop for each (42 stops, a new section "What a box shows you"); its summary now says it covers the map's boundaries in that direction plus the editor, and that what the outside sends only a box (registries, git with a token, an SSH host's or a proxied server's answers) is not a stop. The runtime map gained the actor `editor` (your devices) with channels `cli-editor` and `editor-server`, the latter a boundary that names no check. `security-model.md` lists the editor under "Not defended against"; its pointer to the tour and the overview now say what the tour covers.

The glossary's sealing names the swapped regular file in its definition; the defences row of `data-and-sealing` in `security-model.md` now says a directory swap, and points at the gap row for a regular file. Already LEFTOVER part 7, "Found by the accuracy review" item 6.
